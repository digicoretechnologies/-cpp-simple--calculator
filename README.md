
# 🧮 C++ Simple Calculator

## About
A beginner-friendly calculator developed using C++.

This project performs basic mathematical operations through a console interface.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division-by-zero protection
- Invalid operator handling

## Technologies Used
- C++
- iostream
- switch statements
- Conditional statements

## How to Run
1. Download calculator.cpp.
2. Open it in a C++ compiler.
3. Compile and run the program.
4. Enter two numbers and an operator.

## Example
Input:
7 + 7

Output:
Result: 14
